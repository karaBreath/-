# thaivoice — คุยโต้ตอบด้วยเสียงภาษาไทย และจดจำผู้สนทนาได้

ระบบสนทนาด้วย **เสียงภาษาไทย** ที่รู้ว่ากำลังคุยอยู่กับใคร และจำได้ว่าเคยคุยอะไรกันไว้
ขับเคลื่อนด้วย Claude (`claude-opus-5`) พร้อมชั้นความจำถาวรและการจดจำลายเสียง

```
        พูดภาษาไทย                                              ได้ยินเสียงตอบ
             │                                                        ▲
             ▼                                                        │
    ┌────────────────┐   ┌──────────────┐   ┌─────────────┐   ┌──────────────┐
    │  ไมโครโฟน+VAD  │──▶│  ถอดเสียง    │──▶│   Claude    │──▶│ สังเคราะห์    │
    │  (pre-roll)    │   │  (th-TH)     │   │             │   │ เสียงไทย      │
    └───────┬────────┘   └──────────────┘   └──────┬──────┘   └──────────────┘
            │                                      │  ▲          ตัดเป็นประโยค
            │ ลายเสียง                              │  │          แล้วพูดทันที
            ▼                                      ▼  │
    ┌────────────────┐                       ┌──────────────────────────────┐
    │ รู้ว่าใครพูด    │──────────────────────▶│  ความจำรายบุคคล               │
    │ (voiceprint)   │                       │  ตัวตน · ข้อเท็จจริง · บทสรุป  │
    └────────────────┘                       └──────────────────────────────┘
```

---

## ระบบนี้แก้ปัญหาอะไร

การเอา LLM มาต่อกับ TTS เฉย ๆ แล้วบอกว่าเป็น "ผู้ช่วยเสียงภาษาไทย" มักพังด้วยเหตุผลเดิม ๆ
โครงการนี้จัดการทีละข้อ:

| ปัญหา | สิ่งที่ระบบนี้ทำ |
|---|---|
| ตอบมาเป็น markdown แล้ว TTS อ่านดอกจันออกมา | system prompt สั่งห้าม markdown และมี `clean_for_speech()` กรองซ้ำอีกชั้น |
| ภาษาไทยไม่มีจุดจบประโยค เลยตัดท่อนส่งให้ TTS ไม่ได้ ต้องรอคำตอบครบก้อน | `SpeechChunker` ตัดด้วยเว้นวรรค คำลงท้าย และความยาว ทำให้เริ่มพูดประโยคแรกได้ก่อน |
| ใช้ ครับ/ค่ะ ผิด | คำลงท้ายของบอทมาจากเพศของ *ตัวบอทเอง* (คำลงท้ายไทยบอกเพศคนพูด ไม่ใช่คนฟัง) ส่วนคำลงท้ายของผู้ใช้ถูกจำไว้เพื่อเรียกขานให้เหมาะ |
| คำลงท้ายพ้องกับคำธรรมดา ("ค่าไฟ" "ปวดขา" "คะแนน" ทำให้เดาเพศผิด) | ดูเฉพาะคำลงท้ายที่อยู่ท้ายประโยคจริง ๆ และไม่ใช้คำที่ไม่บอกเพศ (จ้ะ/จ๊ะ/จ้า) |
| ตัดท่อนแล้วคำขาดกลาง ("เขียน" → "เขี" + "ยน") | บังคับตัดที่ขอบคำด้วยตัวตัดคำของ pythainlp และไม่ตัดคั่นวรรณยุกต์ |
| ตัด pre-roll ทิ้ง ทำให้พยางค์แรกหาย วรรณยุกต์เพี้ยน | เก็บเสียงย้อนหลัง 300 มิลลิวินาทีก่อนจุดที่ VAD ตัดสินว่าเริ่มพูด |
| ตัดจบเร็วเกินไปเพราะคนไทยเว้นจังหวะกลางประโยค | ค่าเริ่มต้นรอความเงียบ 800 มิลลิวินาที ปรับได้ |
| จำผู้ใช้ไม่ได้ ต้องแนะนำตัวใหม่ทุกครั้ง | จำจากลายเสียง และมีความจำถาวรรายบุคคล |
| ตัวเลข เวลา เบอร์โทร อ่านออกเสียงผิด | มีตัวแปลงคำอ่านเลขไทย (`ยี่สิบเอ็ด` ไม่ใช่ `สองสิบหนึ่ง`) |

## จดจำผู้สนทนาได้ ในสองความหมาย

### 1. รู้ว่า *ใคร* กำลังพูด

เสียงพูดถูกแปลงเป็นเวกเตอร์ลายเสียง แล้วเทียบ cosine similarity กับทุกคนที่เคยคุยกัน

* ถ้าคล้ายเกิน `threshold` **และ** ทิ้งห่างอันดับสองเกิน `margin` → ถือว่าเป็นคนเดิม
  (เงื่อนไข `margin` มีไว้กันสองคนเสียงคล้ายกันแล้วระบบสลับตัวกลางบทสนทนา)
* ถ้าไม่ใช่ → ระบบจะถามชื่อแบบเป็นกันเอง แล้วผูกลายเสียงกับชื่อนั้นทันที ครั้งหน้าจำได้เอง
* ทุกครั้งที่จำได้ถูก ลายเสียงจะถูกเฉลี่ยสะสม ยิ่งคุยบ่อยยิ่งแม่น

ถ้ายังไม่ได้ติดตั้งโมดูลจำเสียง ระบบยังทำงานได้ปกติ เพียงแต่รู้จักคนจากการบอกชื่อ —
ซึ่งจับได้อัตโนมัติจากประโยคอย่าง "ผมชื่อสมชายครับ" หรือ "เรียกว่าโบทก็ได้"

### 2. จำได้ว่า *เคยคุยอะไร* กันไว้

ความจำแบ่งเป็น 4 ชั้น เก็บใน SQLite:

| ชั้น | เก็บอะไร | อายุ |
|---|---|---|
| `speakers` | ชื่อ ชื่อเล่น คำลงท้ายที่ใช้ เพศที่เดาได้ | ถาวร |
| `voiceprints` | เวกเตอร์ลายเสียงเฉลี่ยสะสม | ถาวร |
| `facts` | ข้อเท็จจริงคีย์-ค่า เช่น `อาชีพ: สถาปนิก` | ถาวร ทับได้ |
| `turns` + `summaries` | บทสนทนาดิบ และบทสรุปสะสมทุก N เทิร์น | ถาวร |

หลังตอบแต่ละครั้ง ระบบจะสกัดความจำ **เบื้องหลัง** (ผู้ใช้ไม่ต้องรอ) ด้วย structured output
โดยเก็บเฉพาะสิ่งที่ควรจำข้ามบทสนทนา และข้ามสิ่งที่ใช้ได้แค่ครั้งนี้

การจำใช้คีย์ทับค่า ดังนั้นถ้าผู้ใช้บอกว่า "ย้ายไปเชียงใหม่แล้ว" ค่าเดิมจะหายไป
ไม่ใช่เก็บสองค่าที่ขัดกัน

## เริ่มใช้งาน

### ติดตั้ง

```bash
git clone <repo> && cd thaivoice
python -m venv .venv && source .venv/bin/activate

pip install -e .                    # แกนหลัก (คุยด้วยการพิมพ์ได้เลย)
pip install -e '.[all]'             # ครบทุกอย่าง: ไมค์ ถอดเสียง เสียงพูด จำลายเสียง เซิร์ฟเวอร์
```

ติดตั้งทีละส่วนก็ได้:

```bash
pip install -e '.[audio]'    # ไมโครโฟน + VAD
pip install -e '.[stt]'      # ถอดเสียงบนเครื่อง (faster-whisper)
pip install -e '.[tts]'      # สังเคราะห์เสียงไทย (edge-tts / gTTS)
pip install -e '.[speaker]'  # จำลายเสียง (resemblyzer)
pip install -e '.[server]'   # HTTP + WebSocket
pip install -e '.[thai]'     # ตัดประโยค/ตัดคำไทยแม่นขึ้น (pythainlp + python-crfsuite)
```

ต้องมี `ffmpeg` ด้วย (มี `ffplay` ที่ใช้เล่นเสียงมาให้)

### ตั้งค่า

```bash
cp .env.example .env
# ใส่ ANTHROPIC_API_KEY ใน .env  (หรือรัน `ant auth login` แล้วไม่ต้องใส่)
```

### ตรวจว่าพร้อมหรือยัง

```bash
thaivoice doctor
```

จะบอกทีละบรรทัดว่าอะไรพร้อม อะไรยังขาด และต้องรันคำสั่งอะไรเพื่อแก้

### คุย

```bash
thaivoice talk      # คุยด้วยเสียงผ่านไมโครโฟน
thaivoice chat      # พิมพ์คุย (ใช้ทดสอบตอนไม่มีไมค์)
thaivoice serve     # เปิดเซิร์ฟเวอร์แล้วเปิด http://127.0.0.1:8080
```

ตัวอย่างบทสนทนาจริง:

```
กำลังฟัง...
คุณ: สวัสดีครับ ผมชื่อเดช เป็นสถาปนิกอยู่เชียงใหม่ครับ
[ผู้พูด: เดช]
บอท: สวัสดีค่ะคุณเดช ยินดีที่ได้รู้จักค่ะ เชียงใหม่ช่วงนี้อากาศเป็นยังไงบ้างคะ

... วันถัดมา เปิดโปรแกรมใหม่ ...

กำลังฟัง...
คุณ: กลับมาแล้วครับ
[ผู้พูด: เดช · ความคล้ายเสียง 0.89]
บอท: กลับมาแล้วเหรอคะคุณเดช งานออกแบบที่เชียงใหม่คืบหน้าบ้างไหมคะ
```

### จัดการความจำ

```bash
thaivoice speakers                          # ดูว่ารู้จักใครบ้าง
thaivoice memory 1 --turns 10               # ดูความจำของคนนั้น
thaivoice enroll --name เดช --wav a.wav b.wav  # สอนให้จำเสียงจากไฟล์
thaivoice forget 1                          # ลบคนนั้นและความจำทั้งหมด
```

```bash
thaivoice forget 1 --memory-only            # ลบเฉพาะความจำ แต่ยังรู้จักตัวเขา
```

ระหว่างคุยก็สั่งได้ตรง ๆ — พูดว่า **"ลืมทุกอย่างเกี่ยวกับฉัน"** หรือ **"ลบความจำทั้งหมด"**
ระบบจะถามยืนยันหนึ่งครั้ง แล้วลบให้จริงทั้งข้อเท็จจริง บทสรุป และบทสนทนา

การตรวจจับคำสั่งนี้ทำด้วยกฎ ไม่ผ่านโมเดล เพราะการลบข้อมูลส่วนบุคคลต้องเชื่อถือได้
100 เปอร์เซ็นต์ และตั้งใจให้ **เข้มงวดจนยอมพลาด** ประโยคอย่าง "อย่าลืมฉันนะ"
"ไม่ต้องลบความจำนะ" หรือ "ลบข้อมูลในมือถือยังไง" จะไม่ทำให้อะไรถูกลบ

## ใช้เป็นไลบรารี (Python)

```python
from thaivoice import create_session

session = create_session()

result = session.exchange("สวัสดีครับ ผมชื่อเดชครับ")
print(result.speaker.call_name)   # เดช
print(result.reply)

# สตรีมเพื่อให้เริ่มพูดได้เร็ว
for event in session.stream_exchange("วันนี้อากาศเป็นยังไง", pcm=audio_bytes):
    if event.type == "chunk":
        play(event.speech.audio)   # พูดทีละประโยคทันทีที่จบประโยค
```

## ใช้จาก TypeScript

```bash
cd typescript && npm install && npm run build
```

```ts
import { ThaiVoiceClient } from "thaivoice-client";

const client = new ThaiVoiceClient({ baseUrl: "http://127.0.0.1:8080" });
const result = await client.chat("สวัสดีครับ ผมชื่อเดชครับ");
console.log(result.speaker?.name, result.reply);
```

คุยด้วยเสียงในเบราว์เซอร์ — ถอดเสียงไทยด้วย Web Speech API (`th-TH`) และส่งเสียงดิบ
ไปด้วยเพื่อให้ระบบจำได้ว่าใครพูด:

```ts
import { VoiceConversation } from "thaivoice-client/browser";

const talk = new VoiceConversation(client, {
  onTranscript: (text, isFinal) => render(text, isFinal),
  onSpeaker: (speaker) => showWhoIsTalking(speaker),
  onReplyDelta: (text) => appendReply(text),
  serverTts: true,   // เสียงจากเซิร์ฟเวอร์ไทยชัดกว่าเสียงในเบราว์เซอร์
  bargeIn: true,     // พูดแทรกได้ (ควรใส่หูฟัง)
});
await talk.start();
```

หน้าเว็บสาธิตพร้อมใช้อยู่ที่ `typescript/web/index.html` — รัน `thaivoice serve` แล้วเปิด
`http://127.0.0.1:8080` ได้เลย

## HTTP API

| Method | Path | ทำอะไร |
|---|---|---|
| `POST` | `/api/chat` | คุยด้วยข้อความล้วน |
| `POST` | `/api/voice` | หนึ่งเทิร์นเต็ม: รับเสียง → รู้ว่าใครพูด → ถอดเสียง → ตอบ → ส่งเสียงกลับ |
| `POST` | `/api/stt` | ถอดเสียงอย่างเดียว |
| `POST` | `/api/tts` | สังเคราะห์เสียงไทยอย่างเดียว |
| `POST` | `/api/identify` | ถามว่าเสียงนี้เป็นของใคร |
| `GET` | `/api/speakers` | รายชื่อคนที่รู้จัก |
| `GET` | `/api/speakers/{id}` | ความจำทั้งหมดของคนนั้น |
| `POST` | `/api/speakers/{id}/enroll` | สอนลายเสียงเพิ่ม |
| `DELETE` | `/api/speakers/{id}` | ลบคนนั้นและความจำทั้งหมด |
| `DELETE` | `/api/speakers/{id}/facts` | ลบเฉพาะข้อเท็จจริง (บทสนทนายังอยู่) |
| `DELETE` | `/api/speakers/{id}/memory` | ลบความจำทั้งหมด — ข้อเท็จจริง บทสรุป บทสนทนา |
| `WS` | `/ws/chat` | สตรีมบทสนทนา (เหตุการณ์ `speaker` → `delta` → `chunk` → `done`) |

เอกสาร OpenAPI อยู่ที่ `/docs`

## การตั้งค่า

ตั้งผ่าน environment variable หรือไฟล์ `.env` (ดูรายการเต็มใน `.env.example`)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `THAIVOICE_MODEL` | `claude-opus-5` | โมเดลที่ใช้สนทนา |
| `THAIVOICE_EFFORT` | `low` | ความลึกในการคิด — บทสนทนาด้วยเสียงควรใช้ `low`/`medium` เพราะ latency สำคัญกว่า |
| `THAIVOICE_STT` | `faster-whisper` | `faster-whisper` \| `google` \| `azure` \| `external` |
| `THAIVOICE_WHISPER_MODEL` | `large-v3` | ภาษาไทยควรใช้ `large-v3` ขึ้นไป โมเดลเล็กผิดเยอะจนคุยไม่รู้เรื่อง |
| `THAIVOICE_TTS` | `edge` | `edge` \| `gtts` \| `azure` \| `browser` \| `none` |
| `THAIVOICE_SPEAKER_BACKEND` | `resemblyzer` | `resemblyzer` \| `speechbrain` \| `none` |
| `THAIVOICE_SPEAKER_THRESHOLD` | `0.75` | ความคล้ายขั้นต่ำที่จะถือว่าเป็นคนเดิม — สูงขึ้น = ระวังตัวมากขึ้น |
| `THAIVOICE_SILENCE_MS` | `800` | รอความเงียบนานเท่าไรจึงถือว่าพูดจบ |
| `THAIVOICE_ASSISTANT_GENDER` | `female` | เพศของ *ตัวบอท* — กำหนดทั้งเสียงและคำลงท้าย ครับ/ค่ะ |

**ปรับ `THAIVOICE_SPEAKER_THRESHOLD` อย่างไร:** ถ้าระบบทักผิดคน ให้เพิ่มค่าขึ้น (เช่น `0.82`)
ถ้าจำคนเดิมไม่ได้บ่อย ๆ ให้ลดลง (เช่น `0.68`) แล้วเก็บตัวอย่างเสียงเพิ่มด้วย `thaivoice enroll`

## ความเป็นส่วนตัว

ระบบนี้เก็บข้อมูลส่วนบุคคล จึงออกแบบให้ควบคุมได้:

* **ความจำทั้งหมดอยู่ในเครื่องคุณ** — SQLite ไฟล์เดียวที่ `data/memory.db` ซึ่ง `.gitignore` กันไว้แล้ว
* **`session_id` ไม่ใช่การยืนยันตัวตน** — เป็นข้อความที่ไคลเอนต์กำหนดเอง ใครส่งค่าเดียวกัน
  มาก็ถือเป็นบทสนทนาเดียวกัน คำขอที่ *ไม่* ส่ง `session_id` จะได้บทสนทนาชั่วคราวที่ไม่จำ
  ว่าเมื่อกี้คุยกับใคร เพื่อไม่ให้คนที่สองสวมรอยเป็นคนแรก ถ้านำไปใช้กับผู้ใช้หลายคนจริง
  ให้ผูก session เข้ากับระบบยืนยันตัวตนของคุณเอง
* **เลือกได้ว่าเสียงจะออกนอกเครื่องไหม** — `THAIVOICE_STT=faster-whisper` ถอดเสียงในเครื่อง
  ส่วน Web Speech API ของ Chrome ส่งเสียงไปประมวลผลที่เซิร์ฟเวอร์ของ Google
* **ลบได้จริงทุกเมื่อ** — พูดว่า "ลืมทุกอย่างเกี่ยวกับฉัน" หรือใช้ `thaivoice forget <id>`
  หรือเรียก `DELETE /api/speakers/{id}` การลบใช้ SQL cascade ลบทั้งลายเสียงและบทสนทนา
* **ระบบสกัดความจำถูกสั่งไม่ให้เก็บข้อมูลอ่อนไหว** เช่น รหัสผ่าน เลขบัตร เลขบัญชี

ลายเสียงเป็นข้อมูลชีวมิติ — ถ้านำไปใช้กับผู้อื่น ควรขอความยินยอมก่อนบันทึก

## ข้อจำกัดที่ควรรู้

* **การจำลายเสียงไม่ใช่ระบบยืนยันตัวตน** — เสียงคล้ายกัน เป็นหวัด หรือไมค์คนละตัว
  ทำให้ผลเปลี่ยนได้ อย่าใช้ตัดสินใจเรื่องความปลอดภัย
* **การจับชื่อจากประโยคแนะนำตัวตั้งใจให้ยอมพลาด** — เพราะการจับผิดจะสร้างตัวตนใหม่
  แล้วผูกลายเสียงเข้ากับตัวตนนั้น ประโยคที่ไม่ชัดจึงถูกปล่อยผ่านและระบบจะถามชื่อแทน
* **การพูดแทรกในเบราว์เซอร์ต้องใส่หูฟัง** ค่าเริ่มต้นคือ *หยุดฟัง* ระหว่างบอทพูด
  เพื่อไม่ให้ระบบถอดเสียงตัวเองแล้วตอบตัวเองวนไม่จบ
* **ต้องต่ออินเทอร์เน็ตเพื่อเรียก Claude** และ `edge-tts` ก็ต้องต่อเน็ตเช่นกัน
  ถ้าต้องการทำงานออฟไลน์ล้วน ต้องเปลี่ยนไปใช้ TTS ในเครื่อง
* **คนชื่อซ้ำกันแยกได้ด้วยเสียงเท่านั้น** — ถ้าคุยผ่านตัวหนังสือ (`/api/chat`) หรือ
  ยังไม่มีลายเสียงเก็บไว้ ระบบจะใช้คนที่ชื่อนั้นซึ่งคุยล่าสุด คนที่พิมพ์ว่า
  "ผมชื่อสมชาย" จึงเห็นความจำของสมชายอีกคนได้ ถ้าต้องการกันจริง ๆ ต้องเปิดการจำเสียง
* **กลับมาคุยด้วยเสียงที่เปลี่ยนไปมาก** (เป็นหวัด ไมค์คนละตัว อยู่ในที่เสียงดัง)
  แล้วบอกชื่อเดิม ระบบจะเลือกใช้ตัวตนเดิมไว้ก่อน แต่จะไม่เอาเสียงครั้งนั้นไปสะสม
  ถ้าเสียงต่างจากเดิมมากจริง ๆ จะถูกแยกเป็นคนใหม่ที่ชื่อซ้ำกัน ซึ่งรวมกลับเองไม่ได้
  ต้องใช้ `thaivoice speakers` ดูแล้วลบตัวที่ไม่ต้องการทิ้ง
* **การพูดแทรกต้องใส่หูฟัง** ไม่งั้นไมค์จะได้ยินเสียงบอทเองแล้วตัดตัวเอง
* **หลายคนพูดพร้อมกันในประโยคเดียว** ระบบยังแยกไม่ได้ — จับได้ทีละคนต่อหนึ่งช่วงพูด
* **prompt caching** เปิดไว้ให้แล้ว แต่ส่วนคงที่อาจสั้นกว่าขั้นต่ำที่แคชได้จริง
  ตรวจได้จาก `usage.cache_read_input_tokens`
